자주 묻는 질문

프로젝트를 저장하고 가져오려면?

앱의 저장 버튼으로 프로젝트 파일을 내보낸 뒤 공유 시트에서 ‘파일에 저장’을 선택하세요. 가져오기 버튼을 누르고 저장한 프로젝트 JSON 파일을 선택하면 다시 편집할 수 있습니다. 작업 중인 장면은 기기에도 자동 저장됩니다.

새 기기에서 작업을 이어갈 수 있나요?

자동 저장은 현재 기기에 보관됩니다. 기기를 바꾸거나 앱을 삭제하기 전에 프로젝트 파일을 내보내 별도로 보관하고, 새 기기의 앱에서 가져오세요. 앱 자체의 계정·클라우드 동기화는 제공하지 않습니다.

부품 배치와 시점 조작은 어떻게 하나요?

부품을 고르고 조립 도구에서 놓을 위치를 선택하세요. 터치 화면에서는 배치 미리보기와 확인 조작을 사용합니다. 화면을 드래그해 시점을 회전하고 두 손가락으로 확대·축소할 수 있습니다.

바퀴와 관절이 움직이나요?

바퀴와 관절 부품을 조립하고 동작 미리보기를 사용할 수 있습니다. 움직임은 연결된 부품의 자세를 보여주며, 실제 충돌이나 중력은 계산하지 않습니다.

언어와 화면 테마는 어디에서 바꾸나요?

앱의 언어 선택 메뉴에서 6개 언어를 선택하세요. 테마 버튼으로 밝은 화면과 어두운 화면을 전환할 수 있습니다. 선택은 기기에 저장됩니다.

광고 개인정보 선택을 바꾸려면?

광고 서비스에서 개인정보 선택이 필요한 지역과 조건에서는 앱의 ‘광고 개인정보 설정’을 이용할 수 있습니다. 광고를 불러오지 못하더라도 블록 편집 기능은 사용할 수 있습니다.
